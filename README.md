## Running locally

Any static file server works. For example:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Deployment

Hosted on GitHub Pages from the `main` branch. Any push to `main` redeploys the site automatically (usually live within ~30 seconds). The custom domain is configured via the `CNAME` file, and `.nojekyll` disables Jekyll processing so files are served as-is.
